# exercicio-notas-portugol
# Exercício de Notas em Portugol  Projeto desenvolvido para praticar lógica de programação utilizando Portugol.  ## Objetivo  Calcular a nota final a partir de duas notas e verificar se o aluno foi aprovado ou não.  ## Conceitos praticados  - Variáveis - Entrada de dados - Operações matemáticas - Estrutura condicional `se/senão`
