# Exercício de Notas em Portugol

Projeto desenvolvido para praticar lógica de programação utilizando Portugol.

## Objetivo

Calcular a nota final a partir de duas notas e verificar se o funcionário  foi aprovado ou não.

## Conceitos praticados

- Variáveis
- Entrada de dados
- Operações matemáticas
- Estrutura condicional `se/senão`

📋 Exemplo de funcionamento

O programa recebe as notas dos dois períodos, soma os valores e apresenta a nota final do funcionário. Quando o resultado não atinge o valor necessário, o programa informa que o funcionário não foi aprovado.

Funcionário aprovado:

Digite a nota do primeiro período: 35.5
Digite a nota do segundo período: 30.0

NOTA FINAL = 65.5
FUNCIONÁRIO APROVADO

Funcionário não aprovado:

Digite a nota do primeiro período: 28.0
Digite a nota do segundo período: 25.5

NOTA FINAL = 53.5
FUNCIONÁRIO NÃO APROVADO
📸 Programa em funcionamento
